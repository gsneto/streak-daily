# streak-daily
Bot de streak diario via GitHub Actions. Roda na nuvem mesmo com PC desligado.

## ligar em 3 passos
1. Cria repo novo no GitHub com esse conteudo e dá push
2. Abre Actions e habilita o workflow daily-streak
3. Roda uma vez manual em Run workflow pra validar

Arquivo que commita todo dia: streak.log
Cron: todo dia 12:00 UTC.
